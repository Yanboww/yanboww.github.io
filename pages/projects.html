enyay-oj

RustDockerMySQLOnline Judge

Enyay-oj is a personal project of Enya and Yanbo (me!), using a Rust backend to serve endpoints. It uses Docker Engine as the sandbox containers for the judge.

Currently, the judge supports C/C++ using the GNU gcc 14 image and Python 3 using the official Docker Python 3 image.

Brookout Tech

SwiftUISpriteKitiOS

Brookout Tech was a group project that was submitted and won first place for the end of year iOS app development contest at BTHS.

It is a stage-based game with 4 levels and more than 50 custom assets. It is created natively for iOS in Xcode, primarily using SwiftUI and SpriteKit.
